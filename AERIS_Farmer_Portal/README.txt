AERIS FARMER PORTAL v1.1

This is a separate local web portal. It does not modify the AERIS Scientist Workbench.

RUN:
  py launch_farmer_portal.py

Then open http://127.0.0.1:8765 in your browser.

INPUT:
  Paste either:
  1. The complete human-readable AERIS console result (Cell / Rank / Rotation / Fitness / seasonal crop explanations), OR
  2. The approved_recommendations.json content.

The portal is a local demonstration. It does not create new agronomic advice or yield guarantees.
